# 🎓 Student Management System

A basic **Student Management System** developed using **C#**, **Windows Forms (WinForms)**, and **.NET 10**. This application allows users to manage student records through a simple graphical user interface.

---

## 🚀 Features

- ➕ Add Student
- ✏️ Update Student Information
- ❌ Delete Student
- 🔍 Search Student by ID or Name
- 🧹 Clear Input Fields
- 📋 Display Student Records in DataGridView

---

## 🛠️ Technologies Used

- C#
- .NET 10
- Windows Forms (WinForms)
- Visual Studio 2022/2025
